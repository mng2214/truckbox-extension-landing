Privacy Policy

Truck Box is a Chrome extension that helps users prepare and send broker outreach emails from supported DAT load board pages using the user's own Gmail account and Google-authorized access. Truck Box is designed to minimize data collection and to use Google data only for user-requested, user-facing functionality.

Important summary: Truck Box can send an email only when the user explicitly clicks to send it. Truck Box does not read the user's Gmail inbox, read Gmail messages, read attachments, or scan mailbox content.

Information we collect

  • Local extension settings. Truck Box may store user-entered settings locally in the browser, such as name, MC number, phone number, templates, filter preferences, and extension settings.
  • Supported page data visible to the user. On supported webpages, Truck Box may read information already visible on the page, such as broker email address, origin, destination, pickup date, equipment, trip length, and similar load details, only to help compose the message the user wants to send.
  • Basic Google account information. During sign-in, Google may provide basic profile information such as account email, profile identifier, and display name for authentication and account access purposes.
  • OAuth tokens. Truck Box uses Google OAuth access tokens only to authenticate approved Google API requests related to sign-in and sending user-requested emails.
  • Account or subscription information. If Truck Box uses a backend for account status, subscription verification, abuse prevention, support, or product security, limited account-level information may be processed for those purposes.

Information we do not collect from Gmail

  • We do not collect or store Gmail inbox messages.
  • We do not read the content of Gmail conversations.
  • We do not access Gmail attachments.
  • We do not scan or analyze a user's mailbox for marketing, profiling, or advertising purposes.

How we use information

  • To send emails the user explicitly requests. Truck Box uses the Gmail API only to send an email when the user chooses to send that email.
  • To compose and populate email content. Supported page data and saved templates are used only to help prepare the draft content and recipient details the user is sending.
  • To authenticate users. Basic Google account information may be used to authenticate the user and confirm authorized access.
  • To provide account, subscription, and security functionality. Limited backend processing may be used for subscription checks, fraud prevention, abuse prevention, operational reliability, and customer support.
  • No advertising use. We do not use Google user data or Gmail-related data for advertising, remarketing, profiling, or personalized ads.
  • No generalized AI training. We do not use Google user data, Gmail-related data, or email content to train generalized artificial intelligence or machine learning models.

Google OAuth scopes

Truck Box requests only the scopes necessary for its user-facing functionality:

  • https://www.googleapis.com/auth/gmail.send — used only to send emails the user explicitly chooses to send.
  • openid — used for secure Google sign-in authentication.
  • email — used to identify the signed-in Google account.
  • profile — used for basic profile information during authentication.
Truck Box does not request Gmail read access. It does not request permission to read inbox messages, read Gmail conversations, access attachments, or manage Gmail settings.

Storage & Security

  • Local-first design. Templates, settings, and preferences are primarily stored locally on the user's device.
  • Limited backend use. If backend services are used, they are limited to account management, subscription verification, security, fraud prevention, abuse prevention, support, and reliable service operation.
  • No sale of personal data. We do not sell personal information, Google user data, or Gmail-related data.
  • No unauthorized sharing. We do not share Google user data except where necessary to provide a user-requested service, for security or legal compliance, or as otherwise permitted by applicable law and Google policy.
  • Reasonable safeguards. We use reasonable administrative, technical, and organizational measures designed to protect the data relevant to operation of Truck Box and related services.

Data deletion & revoking access

  • Users can revoke Google account access at myaccount.google.com/permissions.
  • Users can remove locally stored extension data by clearing extension storage, resetting the extension, or uninstalling the extension.
  • If account, subscription, or support data exists on our backend, users may request deletion by contacting us.
  • After Google access is revoked, Truck Box will no longer be able to send emails through Gmail until the user signs in again.

Your rights

Depending on where you live, you may have rights to request access, correction, deletion, or restriction of personal information we control. Where data is stored only locally in the browser, many of these controls can be exercised directly by the user through browser settings, extension reset, uninstall, or Google permission revocation.

Children's Privacy

Truck Box is not directed to children under 13, and we do not knowingly collect personal information from children.

Changes to this policy

We may update this Privacy Policy from time to time. If we do, we will update the "Last updated" date on this page.

Google API Services User Data Policy

Truck Box's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • User-facing purpose only. Google user data is used only to provide user-facing features that are visible to and initiated by the user.
  • Send-only Gmail access. Gmail API access is used only to send emails that the user explicitly initiates.
  • No inbox reading. Truck Box does not use Google API access to read inbox messages, analyze Gmail conversations, or access Gmail attachments.
  • No advertising use. Google user data is not used to create, target, or improve advertisements.
  • No sale of Google user data. Google user data is not sold.
  • No transfer for unrelated purposes. Google user data is not transferred to third parties except where necessary to provide the user-requested service, for security purposes, to comply with law, or in connection with a business transaction where legally allowed and properly disclosed.
  • No human review of Gmail content. We do not permit humans to read Gmail content unless we have the user's affirmative agreement for specific support or security reasons, or if required by law.
  • No generalized AI or ML training. Google user data is not used to train generalized AI or machine learning models.
