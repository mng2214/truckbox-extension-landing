Privacy Policy

Truck Box is a Chrome extension that helps users compose and send broker emails from one.dat.com using the user's own Gmail account through Google OAuth. We designed Truck Box to minimize data collection and to process data primarily within the user's browser.

Information we collect

  • No server-side collection of Gmail content. We do not collect, store, or process Gmail message bodies, Gmail inbox content, Gmail attachments, or mailbox data on our servers.
  • Local extension settings. User-provided values such as name, MC number, phone number, preferred templates, and extension preferences may be stored locally in chrome.storage.local on the user's device.
  • On-page data visible to the user. The extension may read supported page data such as broker email addresses, origin, destination, pickup date, equipment, or trip length only to help prepare the email the user is sending.
  • Google account basic identity information. During sign-in, Google may provide basic account information such as name, email address, and profile identifier for authentication purposes.
  • OAuth access tokens. Google OAuth tokens are used only to authenticate the Gmail API request needed to send the email the user requested.
  • Operational service data. If a backend service is enabled for account, subscription, security, abuse prevention, or product operation, it may process limited account-level information strictly as needed for that service.

How we use information

  • Send email that the user explicitly requests. Truck Box uses the Gmail API only to send the email message the user intentionally initiates.
  • Populate email fields. Data read from supported webpages is used only to prepare the content requested by the user.
  • Authentication and account access. Basic Google account information may be used only to authenticate the user and determine feature access.
  • Security, reliability, and fraud prevention. Limited operational data may be used to secure the product, prevent abuse, enforce service limits, maintain subscriptions, and troubleshoot technical issues.
  • No advertising use. We do not use Google user data or Gmail data for advertising, remarketing, profiling, or personalized ads.
  • No AI or model training use. We do not use Google user data, Gmail data, or email content to train generalized AI or machine learning models.

Google OAuth scopes

Truck Box requests only the scopes needed for sign-in and sending email:

  • https://www.googleapis.com/auth/gmail.send — used only to send emails the user explicitly chooses to send.
  • openid — used for Google sign-in authentication.
  • email — used to identify the signed-in Google account.
  • profile — used for basic account profile information during authentication.
Important: Truck Box does not request permission to read the user's inbox, read Gmail messages, access Gmail attachments, or manage Gmail settings.

Storage & security

  • Local-first storage. Templates and settings are primarily stored locally on the user's device.
  • Restricted processing. Any backend processing is limited to what is necessary to provide account functionality, subscription access, security controls, abuse prevention, troubleshooting, or product reliability.
  • No sale of personal data. We do not sell personal information or Gmail data.
  • No unauthorized sharing. We do not share Gmail data with third parties except where required by law or where strictly necessary to provide a user-requested service in compliance with applicable Google policies.
  • Reasonable safeguards. We use reasonable administrative, technical, and organizational safeguards designed to protect data relevant to operation of the extension and related services.

Data deletion & revoking access

  • Users can revoke Google account access at myaccount.google.com/permissions.
  • Users can remove local extension data by resetting the extension, clearing browser extension storage, or uninstalling the extension.
  • If server-side account data exists for billing, subscription, security, or support purposes, users may request deletion by contacting us.
  • Revoking Google access prevents Truck Box from sending emails through Gmail until the user signs in again.

Your rights (CPRA/GDPR)

Depending on your jurisdiction, you may have rights to request access, correction, deletion, or restriction of personal data that we control. Where Truck Box stores only local browser data, many of these rights can be exercised directly through browser controls, extension reset, uninstall, or Google account permission revocation.

Children's Privacy

Truck Box is not intended for children under 13, and we do not knowingly collect personal information from children.

Changes to this policy

We may update this Privacy Policy and Terms from time to time. When we do, we will update the last updated date shown on this page.

Compliance: Google API Services User Data Policy (Limited Use)

Truck Box's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Purpose limitation. Google user data is used only to provide or improve user-facing features that are directly visible and requested by the user.
  • Gmail send only. Gmail API access is used only to send emails that the user explicitly initiates.
  • No reading inbox content. Truck Box does not use Google API access to read inbox messages, scan mailbox content, or analyze Gmail conversations for unrelated purposes.
  • No advertising. Google user data is not used to create, target, or improve advertisements.
  • No sale. Google user data is not sold.
  • No transfer for unrelated use. Google user data is not transferred to others except as necessary to provide or secure the user-facing feature, comply with law, or as part of a merger, acquisition, or asset sale where legally permitted and properly disclosed.
  • No human review of Gmail content. We do not allow humans to read Gmail content unless we have the user's affirmative agreement for specific support or security reasons, or unless required by law.
  • No AI training. Google user data is not used to train generalized AI or machine learning models.
